# 项目六：生产级 RAG 知识检索引擎

## 一句话定位

> 基于 TF-IDF 向量 + 倒排索引的混合检索系统，592个知识块、18755个关键词，支持中文语义检索

## 技术栈

Python · ChromaDB · TF-IDF · 中文分词 · FastAPI

## 架构设计

```
用户查询 → 中文分词 → 双路召回 → 加权排序 → 返回结果
              │              │
              ├─ 关键词匹配 ──┤
              │  (倒排索引)  │
              └─ 向量检索 ───┘
                  (TF-IDF)
```

## 关键技术

### 1. 混合检索策略

| 通路 | 算法 | 权重 | 适用场景 |
|:-----|:-----|:----:|:---------|
| **关键词召回** | 倒排索引 + BM25变体 | 35% | 精确匹配、专业术语 |
| **向量召回** | TF-IDF + cosine相似度 | 65% | 语义理解、模糊查询 |
| **融合排序** | 加权调和平均 | - | 综合打分 |

### 2. 中文分词（零依赖）

- 双字滑窗分词（"协议" → ["协", "协议", "议"]）
- 英文单词提取（MCP → ["mcp"]）
- 无需jieba/snownlp，纯正则实现

### 3. 持久化与热加载

- ChromaDB持久化向量数据
- JSON文件缓存倒排索引 + chunks元数据
- 服务重启秒级加载（~100ms）

## 性能指标

- 索引构建：592个块，130个文档，词表3000词
- 检索延迟：<50ms（本地TF-IDF）
- 关键词覆盖：18,755个中文词项
- 内存占用：索引文件647KB

## API 接口

| 端点 | 方法 | 说明 |
|:-----|:-----|:-----|
| `/health` | GET | 健康检查 |
| `/search` | POST | 检索接口 `{query, top_k}` |
| `/refresh` | POST | 重建索引 |
| `/stats` | GET | 索引统计 |
| `/ui` | GET | 检索界面 |

## 成果

**成果：** 生产级RAG检索引擎，支持混合检索、中文分词、持久化热加载，检索延迟<50ms，可作为企业知识库后端服务。
