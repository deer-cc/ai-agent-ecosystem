# 向量检索补齐指南

> 给 RAG 项目加分的知识储备

---

## 一、什么是向量检索

**倒排索引（你现在用的）：**
```
关键词 → 包含它的文档列表
"AI" → [doc1, doc3, doc7]
"创业" → [doc2, doc5, doc7]
```

**向量检索（企业标准）：**
```
把文字转成数字向量，找语义最接近的文档
"AI创业" → [0.23, -0.81, 0.45, ...] 距离最近的文档
```

**区别：** 倒排索引只看"字面匹配"，向量检索理解"语义相似"

## 二、核心概念

### Embedding（嵌入）

把文字变成向量：
```python
# 你不需要手写，用现成库
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')  # 支持中文
vectors = model.encode(["AI创业很难", "人工智能创业不易"])
# 结果：[[0.23, -0.81, ...], [0.25, -0.79, ...]]
# 两条消息向量很接近 → 语义相似
```

### 向量数据库

存储和检索向量的数据库：
| 数据库 | 特点 | 适用场景 |
|:-------|:-----|:---------|
| **Chroma** | 轻量、Python原生、本地运行 | 中小规模，离线场景 ✅ |
| **Milvus** | 高性能、分布式 | 大规模、企业级 |
| **FAISS** | Meta开源、纯检索 | 只需要向量检索 |
| **Qdrant** | Rust编写、带过滤 | 需要复杂过滤条件 |

### 重排序（Rerank）

两步检索：先用倒排索引快速筛选，再用向量检索精排
```
查询 → 倒排索引(快速) → 候选集(100条) → 向量重排序 → Top-5
```

## 三、面试够用版

### 概念要懂

1. **Embedding**：文字 → 向量，语义相近的文字向量距离近
2. **向量数据库**：存向量+加速检索的结构（Chroma/Milvus）
3. **Rerank**：粗排→精排，提升准确率
4. **Chunking**：长文档切成小块再嵌入（通常500-1000字）

### 代码要会写

```python
# 最简单的 RAG 检索（面试手写水平）
import chromadb
from sentence_transformers import SentenceTransformer

# 初始化
model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')
client = chromadb.Client()  # 本地运行
collection = client.create_collection("knowledge")

# 存入知识
docs = ["叶子优先级原则是什么", "dispatcher怎么配置"]
vectors = model.encode(docs).tolist()
collection.add(documents=docs, embeddings=vectors)

# 检索
query = "叶子的优先事项"
query_vec = model.encode([query]).tolist()
results = collection.query(query_embeddings=query_vec, n_results=3)
print(results['documents'][0])  # 返回最相关的文档
```

### 对比要说清

| | 倒排索引 | 向量检索 |
|:---|:---------|:---------|
| 原理 | 关键词匹配 | 语义相似度 |
| 速度 | 极快（毫秒） | 较快（10-100ms） |
| 准确率 | 低（同义词识别不了） | 高（语义理解） |
| 资源 | 极低 | 需要GPU/大内存 |
| 适合 | <1万条离线场景 | >1万条或需要语义理解 |

## 四、加分项（如果能答出来）

**Q: 怎么处理长文档？**
> 分块（Chunking）：按标题/段落切分成500-1000字的块，每块单独嵌入。检索时返回包含最多匹配块的文档。

**Q: 向量检索有什么缺陷？**
> 1. 需要重新索引（数据变化时）2. 冷启动慢（首次构建索引耗时长）3. 中文Embedding质量参差（需要选好的模型）

**Q: 你的项目如果升级会怎么做？**
> 保留倒排索引做预处理快速筛选，叠加 Chroma 做向量精排，加一个 rerank 模型（如 BGE-Reranker）做最终排序。
