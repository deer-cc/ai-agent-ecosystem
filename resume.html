◆ 核心项目
1. Multi-Agent LLM 编排系统 Python · JSON协议 · Claude Code Skills
设计并实现「规划层 + 执行层」分离的多 Agent 系统。叶子（战略预判）输出 JSON 指令，执行器解析执行并回执，两者互不耦合。定义了15个原子Action和11个错误码，全覆盖错误场景。监护系统：连续100条无回执或超时30s → SIGTERM强制终止。三级安全边界防止误操作。用户画像自适应学习 + 执行复盘机制。
成果：7个项目全生命周期追踪，8条决策记录，5种沟通模式自动识别
2. cc-connect 跨平台消息桥接 Go · WebSocket · JSON-RPC
构建 Claude Code ↔ 飞书/Telegram 的通信中间层。WebSocket长连接 + HTTP主动推送双通道。定时任务调度（cron + timer）。Bot中继功能支持跨Bot对话。解决了多进程抢占同一飞书凭证的竞态问题。双层守护（watchdog + guardian）保障可用性。
成果：延迟<200ms，可用性99%+，单凭证独享会话
3. 桌面自动化服务 v2 Python · Win32 API · pyautogui
用 Python 原生调用 Win32 API 替代 PowerShell 管道方案。10个HTTP API端点（截图/点击/输入/窗口管理等）。去除中间层后延迟从500ms降至50ms（10倍提升）。原生UTF-8中文输入，解决GBK乱码。紧急停止机制（鼠标移到左上角触发FAILSAFE）。开机自启+异常自动重启。
成果：10个API全部通过端到端测试
4. 本地 RAG 知识检索系统 Python · 倒排索引 · Obsidian
基于 Obsidian 知识库的本地语义检索引擎，完全离线运行。倒排索引 + H1-H4层级权重评分。意图识别矩阵：知识/项目/决策/上下文四类请求自动路由。PARA结构管理。支持跨会话上下文注入。
成果：延迟<100ms，74个知识节点，零外部API依赖
5. 服务治理与高可用架构 Python · 指数退避 · 消息队列
三层服务治理架构：guardian（60s巡检+3次失败自动重启）、dispatcher（去重5min窗口+指数退避重试5s/15s/30s+本地队列持久化）、watchdog（文件+进程+MCP健康诊断）。配置驱动JSON管理，支持热更新。5个服务纳入开机自启流程。
成果：5服务全自动守护，重启补发零丢失
6. 闲鱼自动客服系统 Node.js · WebSocket · LLM
独立开发的闲鱼消息自动回复系统。WebSocket监听实时响应。LLM意图识别自动分类售前问题。支持图片/文字/链接多类型消息。多轮对话保持上下文。
成果：秒级响应，释放人工客服时间
